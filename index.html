GraphFlow: system design diagrams that run

GraphFlow is a browser-based distributed systems modeler with a live simulation. Draw services, queues, caches and databases, then send simulated traffic through them and watch utilization, p95/p99 latency, backpressure, circuit breakers and failures happen in real time. No install and no sign-in needed to try it.

What you can do

  • Model an architecture and stress it with a load slider and per-node fault injection.
  • Import docker-compose.yml, Terraform, draw.io, Excalidraw and Mermaid diagrams.
  • Export Mermaid, SVG/PNG, Terraform, Kubernetes manifests and k6 load-test scripts (some exports are Pro).

Try a live example

  • Stripe-style webhook and double-entry ledger
  • Edge streaming under chaos
  • CQRS with a Kafka outbox
